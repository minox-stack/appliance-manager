# إدارة أسعار الأجهزة — Liquid Glass (PWA للآيفون)

تطبيق شخصي بالعربية (RTL) لتسجيل **سعر الكاش** و**سعر التقسيط** للأجهزة المنزلية والبحث عنها فورًا.
React + TypeScript + Vite + Dexie (IndexedDB). كل البيانات تبقى على جهازك فقط.

## التشغيل على حاسوبك

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run dev          # تطوير: http://localhost:5173 (ويظهر عنوان الشبكة لتجربته من الآيفون)
npm run typecheck    # فحص TypeScript
npm test             # اختبارات البحث والنسخ الاحتياطي و CSV
npm run build        # بناء الإنتاج في مجلد dist/
npm run preview      # تجربة نسخة الإنتاج محليًا
```

> ملاحظة: الـ Service Worker يعمل في نسخة الإنتاج فقط (`build` + `preview`)، وليس في `dev`.

## النشر على HTTPS (مطلوب للتثبيت على الآيفون و«بدون إنترنت»)

مخرجات `dist/` ملفات ثابتة، ومسارها نسبي فتعمل في أي نطاق أو مجلد فرعي. أسهل الخيارات المجانية:

- **Netlify:** اسحب مجلد `dist` إلى netlify.com/drop.
- **Cloudflare Pages:** `npx wrangler pages deploy dist`.
- **GitHub Pages:** ارفع محتوى `dist` إلى فرع `gh-pages`.
- **Vercel:** `npx vercel --prod` من داخل `dist`.

مهم: ثبّت عنوان موقعك ولا تغيّره لاحقًا. بيانات IndexedDB مرتبطة بالعنوان، وتغيير النطاق يعني قاعدة بيانات فارغة
(استعد نسختك الاحتياطية عندها).

## التثبيت على الآيفون

1. افتح الموقع في Safari. 2. اضغط «المشاركة». 3. «إضافة إلى الشاشة الرئيسية». 4. «إضافة».

## النسخ الاحتياطي والاستعادة

من تبويب **الإعدادات**:

- **تصدير نسخة احتياطية:** ملف JSON فيه الأجهزة والتصنيفات والمفضلة والصور. اختر «حفظ / مشاركة» ثم «حفظ في الملفات».
- **استعادة:** اختر الملف، ستظهر معاينة (عدد الأجهزة والتصنيفات والصور)، ثم اختر:
  - **دمج:** يضيف الجديد ويحتفظ بالأحدث تعديلًا عند التكرار، ولا يحذف شيئًا.
  - **استبدال الكل:** يحذف الحالي (يتطلب تأكيدًا صريحًا).
  الاستعادة داخل معاملة واحدة: إما تنجح كلها أو لا يتغير شيء. الملفات التالفة تُرفض برسالة عربية.
- **CSV:** جدول للعرض في Excel (بلا صور، ولا يصلح للاستعادة).
- **مسح كل البيانات:** يتطلب كتابة كلمة «مسح».

خذ نسخة احتياطية بانتظام، فالتخزين المحلي يمكن أن يُمسح.

## بنية المشروع

```
src/
  db/        database.ts (Dexie + إصدارات)، repo.ts (CRUD)، backup.ts (تصدير/استعادة)
  lib/       البحث، التنسيق، CSV، صيغة النسخة الاحتياطية، معالجة الصور، المسودات
  app/       الحالة العامة، التنقل، التصفية
  screens/   الرئيسية، المنتجات، التفاصيل، النموذج، التصنيفات، الإعدادات
  ui/        مكوّنات مشتركة (بطاقة، ورقة سفلية، شريط التنقل، إشعارات…)
  styles.css نظام التصميم (متغيرات CSS)
public/      sw.js، manifest، الأيقونات
tests/       اختبارات المنطق
```

لتغيير بنية قاعدة البيانات مستقبلًا: أضف `this.version(2).stores(...).upgrade(...)` في `src/db/database.ts` ولا تعدّل `version(1)`.

## الميزات

بحث فوري (اسم، ماركة، موديل، تصنيف، وصف، مواصفات) مع توحيد الحروف العربية، ومرادفات الماركات (كوندور/Condor)،
ومطابقة الموديل بلا شرطات (`rs25` تجد `RS-25`)؛ ترتيب بالأحدث/الاسم/سعر الكاش/سعر التقسيط؛ مفضلة؛ تصنيفات
مع حذف آمن (نقل الأجهزة)؛ صور بالكاميرا أو المكتبة مع ضغط وتصغير؛ مسودة النموذج تُحفظ تلقائيًا؛ تأكيد قبل الحذف؛
PWA مع Service Worker لواجهة التطبيق فقط.

## حدود معروفة

- البيانات محلية على جهاز واحد، ولا مزامنة بين الأجهزة. لا تشفير ولا قفل تطبيق.
- iOS قد يمسح بيانات المواقع غير المستخدمة لفترة طويلة (خصوصًا خارج الشاشة الرئيسية)؛ التثبيت على الشاشة الرئيسية والنسخ الاحتياطي يقلّلان المخاطرة.
- لا توجد اختبارات آلية للواجهة، فجرّبها يدويًا على الآيفون قبل الاعتماد عليها.
